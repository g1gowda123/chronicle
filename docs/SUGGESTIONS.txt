2. WHAT CHANGED ON THE ROLE C SIDE
----------------------------------
  - Bounded verification queue (size 8 by default). Same clip_id is never
    verified twice. Full queue either drops the oldest clip (freshest state
    wins) or rejects the newest, per CHRONICLE_VERIFICATION_QUEUE_POLICY.
  - Queue metrics: QUEUE_DEPTH, QUEUE_BACKPRESSURE, CLIP_DEDUPLICATED,
    VERIFICATION_LATENCY, VERIFICATION_FAILED. Also
    runtime.verification_stats for polling.
  - Per-action acceptance thresholds plus a global floor. OTHER is never
    accepted. Hedged captions ("appears", "maybe", "unclear", "?") are
    penalised and rejected.
  - Container extraction from the caption/pipeline hint, action-aware:
    "out of the drawer ... into the pocket" resolves correctly for
    REMOVE_FROM vs INSERT_INTO. Explicit container still wins.
  - GraphRAG evaluation set with location, time, action, remove, lost,
    zone-only and unknown cases. Citation precision is checked per answer.
    "when" queries now select the latest entity fact rather than the latest
    spatial fact.
  - `chronicle run` / `ChronicleRuntime` uses the Role C queue internally.
    Public runtime API and snapshot schema are unchanged (TASK-C1 added
    snapshot()["verification_stats"]).
  - Labelled captions can now live outside the code:
      python -m chronicle.semantic.calibration --labels labels.jsonl
    writes the CHRONICLE_ACTION_THRESHOLDS=... line and exits non-zero if the
    target precision is not reached. See docs/calibration_labels.example.json.
  - Action timelines can be scored against a snapshot export or a predictions
    file, so the "done when" bar is measurable without touching code:
      python -m chronicle.semantic.timeline \
        --labels runs/hololens_timeline.json \
        --snapshot runs/chronicle_snapshot.json --tolerance 2.0
    Exit 0 requires precision=recall=1 and entity/container agreement where
    comparable. See docs/action_timeline.example.json.


3. SUGGESTED NEXT STEPS - ROLE A (PERCEPTION)
---------------------------------------------
3.1 Put container/contact evidence into clip metadata
    Role C reads clip.metadata["container"] and ["context_hint"] already.
    Emitting them from Role A's geometric reasoning beats caption inference.

3.2 Share one OpenCLIP model
    Pass Role A's EmbeddingService as embedder= to SemanticEngine. Role C
    wraps it with PerceptionEmbedderAdapter, so ViT-B-32 is loaded once for
    both Re-ID and place recognition.

3.3 Clip ids must be unique and stable
    The queue de-duplicates on clip_id. Reusing an id across distinct
    interactions silently drops the second one.

3.4 Keep tests green
    `pytest tests/test_role_a_integration.py` is the cross-role guard for
    InteractionClip/ClipFrame shape changes.


4. SUGGESTED NEXT STEPS - ROLE B (GRAPH / STATE)
------------------------------------------------
4.1 Consume accepted actions only
    VLM ACTION_VERIFIED carries accepted, source (llm/rule), confidence,
    container and clip correlation fields. Rejected actions still arrive for
    the review queue; do not write them as facts.

4.2 Use the container field
    INSERT_INTO / REMOVE_FROM now carry a cleaned container noun phrase.
    Prefer it over parsing the evidence sentence.

4.3 Feed answer_query a 2-hop subgraph
    Keep entity + last-known zone + facts with real timestamps. GraphRAG drops
    any cited timestamp that is not in the payload.

4.4 Persist zones deliberately
    Zone prototypes are in-memory + JSON in Role C. If SQLite is the source of
    truth, persist match.as_event() / Zone.to_dict() and reload at startup.


5. SUGGESTED NEXT STEPS - ROLE D (UI / DASHBOARD)
-------------------------------------------------
5.1 Show queue health
    Subscribe to QUEUE_DEPTH / QUEUE_BACKPRESSURE or poll
    runtime.verification_stats. Suggested fields: depth, max_pending, dropped,
    duplicates, avg_latency_ms, max_latency_ms.

5.2 Flag rejected/ambiguous actions
    action.accepted == false includes hedged captions at high raw confidence.
    Show them in the review drawer with the strip preview
    (result.to_dict(include_preview=True)).

5.3 Show grounding provenance
    QueryAnswer exposes source (llm/template), grounded and citations. Render
    grounded=false distinctly.

5.4 Keep VLM work off the UI thread
    Use engine.verification_service().start()/stop() or the runtime queue;
    Florence-2 + Ollama calls are blocking.

  CHRONICLE_CLIP_MODEL_NAME        ViT-B-32
  CHRONICLE_CLIP_PRETRAINED        laion2b_s34b_b79k
  CHRONICLE_DEVICE                 cpu | cuda | mps
  CHRONICLE_FLORENCE_MODEL_ID      microsoft/Florence-2-base
  CHRONICLE_LLM_BACKEND            auto | ollama | transformers | template | none
  CHRONICLE_VPR_THRESHOLD          0.85
  CHRONICLE_ACTION_MIN_CONFIDENCE  0.45
  CHRONICLE_ACTION_THRESHOLDS      HOLD=0.7,PICK_UP=0.8 (optional override)
  CHRONICLE_VERIFICATION_QUEUE_SIZE 8
  CHRONICLE_VERIFICATION_QUEUE_POLICY drop_oldest | reject

  `auto` only probes Ollama; it never downloads a multi-GB model during
  ingestion. Set llm_backend="transformers" explicitly for a local HF model.
  First OpenCLIP / Florence-2 construction downloads weights from Hugging Face.


7. KNOWN LIMITATIONS
--------------------
  - Action classification is caption-then-text-classify, not a true VLM call.
    Replace ActionVerifier.chat_client with a vision client to change that;
    the schema and fallbacks stay the same.
  - Calibration ships with a 16-caption seed set. Put real HoloLens labels in a
    JSON/JSONL file and run
    `python -m chronicle.semantic.calibration --labels <file>`; commit the
    resulting thresholds once the timeline is labelled. The timeline scorer is
    ready (`python -m chronicle.semantic.timeline --labels <file> --snapshot
    <export>`); only the labelled real footage is missing for the "done when"
    bar in TEAM_STATUS.
  - The deterministic HSV embedder is demo/test-only.
  - GraphRAG grounds timestamps and zones but does not re-rank entities with
    CLIP text-to-node similarity yet.
  - Heavily occluded revisits can still create a second zone; tune
    CHRONICLE_VPR_THRESHOLD / CHRONICLE_VPR_MIN_MARGIN on real footage.
